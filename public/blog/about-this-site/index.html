June 25, 2025

When I created my personal website using lekh, I thought I'll never need to touch it again.

But I was wrong.

Over time, Rust has taken a special place in my IDE and it has almost replaced every other language I use.

While Hugo is great, I think I fell for my love for Rust and ended up porting the theme to Zola. The ported theme is called lekhz Porting the theme was way easier than I thought it would be with the advent of AI powered code editors.

I'm not sure if I'll ever need to touch it again. The hope is to make it last long, but not long enough, as with everything else, the nature shall take its course.
